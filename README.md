# 🌦️ Weather App

A Java-based web application that displays **real-time weather information** for any city using the **OpenWeatherMap API**.  
The application fetches live data and presents it in a clean, user-friendly interface.

---

## 🚀 Features

- 🌍 Search weather by **city name**
- 🌡️ Displays **temperature**, **humidity**, and **weather conditions**
- 🔄 Fetches **real-time data** from OpenWeatherMap API
- 🎨 Clean, responsive, and easy-to-use UI
- ⚡ Fast API response with JSON parsing

## ⚙️ How It Works

1. User enters a **city name**
2. Application sends request to **OpenWeatherMap API**
3. API returns weather data in **JSON format**
4. Java backend parses the response
5. Weather details are displayed on the UI
